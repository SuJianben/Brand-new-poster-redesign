# 2026-11-10 首页编辑器模块化

- 目标：在不改变现有首页设计的前提下，让测试店主题编辑器分别管理页头、首页区块与页脚。
- 修改范围：自建主题布局、首页模板与 React 首页；不使用 Shopify 默认主题。
- 新增：header/footer section group、12 个自定义 section，以及按首页功能拆分的 React 组件、共享状态、数据与图标模块。各区块支持在 Shopify 编辑器内调整顺序和显示状态；主要标题、公告、滚动文字、轮播标题与描述、轮播/活动/品牌图片、页头页脚导航文字及链接、页脚品牌简介提供编辑项；系列、社区、文章、FAQ 的条目可单独编辑、排序和增删。
- 调整：移除旧的单一首页 section；主题资源通过 `pnpm build:shopify` 重新生成，原始全局样式文件未改动。
- 影响：通过 GitHub main 连接的测试店主题将自动同步；该主题在 test-app-english.myshopify.com 中当前处于已发布状态。主题同步前已备份至项目上级的 backups 目录。
- 自检：构建、TypeScript 和 Shopify Theme Check 通过；本地模拟 Shopify 区块渲染，桌面和手机对照原稿尺寸一致，测试轮播、分类、购物袋、编辑标题和 FAQ 条目、区块重排和区块刷新时共享状态。
- 遗留：商品卡片及部分文案仍为源码演示数据，尚不能逐条在编辑器内配置；尚未接入真实 Shopify 商品、购物袋及结账。截图为本地模拟，主题文件已同步到测试店；由于浏览器标签连接报错，实际 Shopify 编辑器保存操作尚未验证。其他页面的模板尚未开发。
