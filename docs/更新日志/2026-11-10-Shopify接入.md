# 2026-11-10 Shopify 测试主题接入准备

- 目标：使现有首页原型具备 Shopify GitHub 主题连接所需结构，供测试店预览。
- 范围：新增自建的主题布局、首页 section 和模板、必要配置、编译文件及独立构建配置；保留现有 React、TypeScript 和页面样式，不使用 Shopify 默认主题。
- 新增：`layout/`、`sections/`、`templates/`、`config/`、`locales/`、`assets/` 中的主题文件，`vite.shopify.config.ts` 和本记录。
- 调整：`package.json` 增加 `build:shopify` 命令；修改首页源码后须运行 `pnpm build:shopify` 并提交生成的两个 assets 文件，否则 Shopify 不会获取最新页面。
- 影响：GitHub main 分支具备首页原型的主题结构；尚未上传或发布店铺主题。
- 自检：Shopify Theme Check、TypeScript 检查、主题构建通过；本地模拟 Shopify 布局，桌面及手机页面、轮播、筛选、购物袋演示交互通过，未发现页面运行错误。模拟不能代替真实 Shopify 连接验证。
- 遗留：尚未测试与指定测试店的真实 GitHub 连接；仅首页原型，商品、购物袋、订阅和结账均未接入 Shopify，内容为演示数据；非首页模板、主题编辑器设置、埋点和正式商店功能尚待后续设计开发。外部图片和字体仍依赖原稿资源。
